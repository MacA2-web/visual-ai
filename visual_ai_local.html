Memory & privacy controls

Chat history and learned observation notes are stored in this browser's local storage. They are not sent to a cloud AI service by this page. Clearing site data will erase them.

Model and browser notes

This page uses WebLLM with WebGPU. It needs a compatible browser/device, enough available memory, and internet for the initial model download. The model is cached by the browser when supported. For camera access, open this page from HTTPS or localhost.

The AI is a language model, not a conscious being. It does not independently train itself; it can use saved notes and camera detections as context.

Local-first prototype. Model execution happens on your device when WebGPU is available. External downloads are required for the WebLLM library, model weights, and optional vision library.
